## Overview

Aptakube is a lightweight, modern, multi-cluster desktop client for Kubernetes. 
<br/> 
Built with Rust, which means fast startup, a tiny install size, and a native feel on every platform.

Used by top engineers at companies like Grafana, Airbus, Supabase, Axiom, and many other companies

## Features

- 💯 **Multi-cluster** — connect to and view multiple clusters simultaneously, no tab-switching
- 🗂️ **Multi-tabs** — open multiple resources and views side by side in tabs, just like a browser
- 🚦 **Workload Overview** — instantly spot failing pods, broken deployments, undersized containers, and warning events
- ⚡️ **Aggregated Log Viewer** — stream live and historical logs from multiple pods/containers at once, with filtering and export
- 📊 **Pod & Node Metrics** — CPU/memory usage across nodes and workloads, works with metrics-server and Prometheus
- 🔌 **One-click Port Forwarding** — no more remembering `kubectl port-forward` syntax
- ⚖️ **Resource Diff** — compare resources across clusters or namespaces to spot configuration drift
- ✌️ **Multi-Namespace Selector** — filter and browse across namespaces at once
- 💪 **Human-friendly resource view** — see what matters without wading through raw YAML
- ✍️ **View, create & modify objects** — full YAML editing when you need it
- ⚡ **Quick Actions** — restart, scale, delete, and more, without memorizing commands
- 🗂️ **Multi-tabs** — open multiple resources and views side by side in tabs, just like a browser, so you can jump between a Deployment, its Pods, and a log stream without losing your place
- 🎉 **Zero-config setup** — reads your existing kubeconfig, doesn't touch your CLI workflow
- 😉 **NOT** another Electron app — built with Tauri for a fast, tiny, native experience
- 🔒 **Runs locally** — connects directly to your cluster's API server; your data never leaves your machine
- ✅ Works with any Kubernetes cluster: on-prem, GKE, EKS, AKS, OpenShift, Talos, Rancher and others
- 💻 Available on **Windows**, **macOS** and **Linux**

Visit **[aptakube.com](https://aptakube.com?utm_campaign=github_readme)** to learn more and see it in action.

## Security

Aptakube connects directly from your machine to your cluster's API server, your cluster data, logs, and connection settings never leave your device, and nothing is installed on the cluster itself. Read more in the [security documentation](https://aptakube.com/docs/security).
